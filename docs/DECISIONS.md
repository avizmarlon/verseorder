# VerseOrder — Decisions and open questions

Last reviewed: 2026-10-17. This is the concise product record. The full requirements are in `PRODUCT_SPEC.md`; work is sequenced in `ROADMAP.md`.

## Accepted

| Decision | Outcome | Rationale |
| --- | --- | --- |
| Project identity | **VerseOrder** | Short independent identity with room to expand. |
| Subtitle | **The Ultimate Marvel Multiverse Watch Order** | Communicates the current editorial scope clearly. |
| Repository | **Public, open-source, from the beginning** | Accessible contributions and transparent code. |
| Audience | **First-time viewers and returning fans** | Spoiler-aware and contextual viewing. |
| Localization | **EN and PT-BR from the beginning** | Broader discoverability with accessible experiences. |
| Editorial approach | **Selective, narrative-first watch order** | Emotional impact, context and enjoyable reveals over rigid dates. |
| Content baseline | **110 entries from July 2026**, under editorial review | Retain original order as a starting dataset without asserting it is fully current. |
| Exclusions | **Separate document**, not a second main sequence | One canonical list for viewers. |
| Visual ambition | **Art-directed, immersive, animated, cinematic, custom work** | Not a generic catalogue or template. |
| Prototyping | **Three interactive concepts before a final design** | Compare direct experiences rather than choose from descriptions. |
| Interactions | **Hover expansion, contextual detail, motion, optional verified trailers** | Premium feeling without unbounded autoplay or excessive downloads. |
| Initial stack | **Next.js / React / TypeScript + Tailwind + Motion + GSAP** | Flexible React app foundation; static export first. |
| 3D | **Selective Three.js / R3F later, when justified** | Performance and complexity matter as much as visual flair. |
| Storage | **Local browser storage first; no accounts yet** | Fast and free initial release. |
| Future growth | **Accounts, sync, profiles, favorites, likes, suggestions, comments, discussions, moderation** | Retained roadmap, not in initial scope. |
| Spending | **No paid infrastructure without a deliberate decision** | Keep costs predictable. |

## Still undecided

- Which prototype becomes the home/navigation foundation, and which interactions are combined.
- Site hosting and domain; repository is public but production hosting is not set.
- Full poster/image provider and legal attribution process, consistent with fan-use rights.
- Exact finished launch timeline after editorial source review.
- Auth/database vendor when member features become justified by actual usage.
- Character connection graphs, episode-level watch positions and advanced 3D effects based on research and performance.

## Editorial review needed

The 110-item original is a baseline, **not** proof of current release completeness or a Marvel-endorsed order. New content and placements must be evaluated in relation to actual releases and spoiler/character continuity; corrections should record the source and why the viewing experience improves.
